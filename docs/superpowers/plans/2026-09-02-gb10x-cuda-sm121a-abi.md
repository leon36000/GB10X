# GB10X CUDA `sm_121a` ABI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the fail-closed CUDA `sm_121a` build surface and fixed v1 Rust/C ABI without introducing an inference path.

**Architecture:** Keep the Rust workspace host-independent by representing the ABI in `gb10x-runtime` without linking CUDA from a default target. A standalone, opt-in CMake project owns the native static library and a single GPU-probe smoke executable. CMake rejects every unsupported host/compiler/architecture path and passes the exact `compute_121a -> sm_121a` code-generation pair itself.

**Tech Stack:** Rust stable (edition 2024), C11-compatible header, CUDA C++17/NVIDIA `nvcc`, CMake 3.24+, CTest.

**Spec:** `docs/superpowers/specs/2026-09-02-gb10x-cuda-sm121a-abi-design.md`

## Execution checkpoint — 2026-09-02

has no CMake, `nvcc`, CUDA runtime, or GB10/DGX Spark, so its remaining native

## Global Constraints

- The production target is NVIDIA GB10 / DGX Spark on Linux `aarch64` only; M3 does not support x86, cross-compilation, or another GPU.
- The only generated CUDA code image is `--generate-code=arch=compute_121a,code=sm_121a`; no PTX image, `native`, `all`, `all-major`, `--gpu-architecture`, `--gpu-code`, or second `--generate-code` option is allowed.
- CUDA activation is opt-in through `GB10X_CUDA_ENABLE=ON`; default configuration must not discover a CUDA toolkit or create a CUDA target.
- The enabled CMake build accepts only NVIDIA `nvcc`, an exact `sm_121a` token in `--list-gpu-code`, and an exact `compute_121a` token in `--list-gpu-arch`.
- `gb10x_cuda` is a static library; M3 does not add a Rust linker/build-script integration or any CUDA invocation from the default Rust workspace.
- ABI v1 fields, sizes, alignments, status codes, and meanings are immutable. Both output structures require the caller to initialize `struct_size` to the exact v1 size.
- Existing GitHub Actions remains Rust-only. Native CUDA validation is documented and remains unverified until it is run on a GB10/DGX Spark host.
- The present workspace has `cc` but no `cargo`, `rustc`, `cmake`, `nvcc`, or NVIDIA device utility. Do not report host Rust/CMake/CUDA checks as executed here when they were not.
- No GDN, QSA, MoE, MTP, KV, quantization, model-loading, tensor allocation, generic fallback, or performance behavior is added.

function(gb10x_require_nvcc_token option expected)
  execute_process(
    COMMAND "${CMAKE_CUDA_COMPILER}" "${option}"
    RESULT_VARIABLE result
    OUTPUT_VARIABLE output
    ERROR_VARIABLE error)
  if(NOT result EQUAL 0)
    message(FATAL_ERROR "nvcc ${option} failed (${result}): ${error}")
  endif()
  string(REGEX MATCH "(^|[ \t\r\n])${expected}($|[ \t\r\n])" found "${output}")
  if(found STREQUAL "")
    message(FATAL_ERROR "nvcc ${option} does not report ${expected}: ${output}")
  endif()
